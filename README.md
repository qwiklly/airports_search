# Airports Search

Консольное приложение для поиска аэропортов в файле `airports.dat`.

Пользователь выбирает колонку, вводит начало искомого значения и получает список подходящих строк, а также время выполнения поиска.

## Как это работает

При запуске приложение строит индекс по первым двум символам каждого значения. Индекс хранит позиции соответствующих строк в файле, поэтому весь файл не загружается в оперативную память.

Результаты поиска сортируются по найденному значению. Числовые значения сравниваются как числа, а не как строки.

## Запуск

Для работы приложения требуется .NET 8.

```bash
cd "autocomplete test task"
dotnet run
```

После запуска:

1. Введи номер колонки (нумерация начинается с 1).
2. Введи начало значения для поиска.
3. Получи результаты поиска и время его выполнения.

Для завершения работы приложения введите `!quit`.
